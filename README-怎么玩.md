# 《地堡搭档》—— 双人在线末日生存合作游戏

> 原创 HTML5 小游戏:两人一起 60 秒抢物资 → 躲进地堡过 10 天 → 活到救援就是胜利。
> 两台手机联机,无需服务器账号,房间码直连。

## 🎮 立即开玩(线上版,已部署)

**https://189970574.github.io/duobunker/**

1. 把链接微信发给朋友,两台手机浏览器打开
2. 一人点「创建房间」,把 5 位房间码发给朋友
3. 朋友点「加入房间」输码(或直接打开 `链接?房间码` 自动进房)
4. 房主点「开始搜刮!」——开玩!

## 一、怎么和朋友联机玩(两条路任选)

### 路线 A:打包成 APK(免打开浏览器,微信直接发文件)

1. 把整个 `bunker-duo-apk` 文件夹传到你手机上(压缩 zip 后微信传,解压到 Termux home,如 `~/duobunker`)
2. 手机 Termux 里执行:
   ```bash
   cd ~/duobunker
   bash 一键打包APK.sh
   ```
   首次缺依赖按提示装:`pkg install android-tools openjdk-17 apksigner python`
3. 得到 `地堡搭档-日期.apk`,**微信发给朋友,你自己也装一份**
4. 开玩:一人点「创建房间」→ 把 5 位房间码发给朋友 → 朋友点「加入房间」输码 → 房主点「开始搜刮!」

### 路线 B:网页版(免安装)

把 `bunker-duo` 文件夹部署到任意静态托管(GitHub Pages / 任意静态空间),
两台手机浏览器打开同一网址,一人创建房间、一人输码。
联机走公共 MQTT 中继(broker-cn.emqx.io),游戏文件本身放哪里都行,甚至局域网 `node serve.js` 也能玩(同一 WiFi)。

## 二、玩法说明

- **搜刮阶段(60 秒)**:两台手机看到同一个屋子,先点先得;每个背包上限 8 格;
  🛢️桶装水 / ⚡汽油发电机 是**大件**,必须两人各点一次才能搬走——分工与合作!
- **地堡阶段(10 天)**:每天一张事件卡,三种类型:
  - 🤝 **暗选同亮**:两人各自选,组合出结果(开不开门?)
  - 👉 **值班决策**:单数天房主决定、双数天队友决定
  - ✊ **合力挑战**:两人一起狂点按钮,凑够次数就成功
- **资源**:🥫罐头=食物、🧴瓶装水=饮水,每人每天吃 1 喝 1;
  断粮掉健康 ❤️,地堡沉闷掉理智 🙂,🧸玩偶/🃏扑克/⚡发电机每天回士气
- **特殊物品**:😷防毒面具、📻收音机、🔋电池、🔦手电、🔫步枪+🧨弹药、💊急救包……都会在对应事件里派上用场
- **结局**:第 10 天救援到来,按双方状态分 S/A/B 级;中途双人阵亡也有结局 C

## 三、技术说明(给开发者)

- 纯 HTML5 + 原生 JS,零构建;`index.html` + `js/{mqtt.min.js, net.js, data.js, game.js}`
- 联机:MQTT over WSS,优先 `broker-cn.emqx.io:8084`,失败自动轮换 `broker.emqx.io`;
  房间 = 5 位随机码,主题 `duobunker/v1/<房间码>/{c2h,h2c}`
- 架构:房主权威模拟(全部随机与结算在房主端),队友端纯镜像;
  断线自动重连 + 重新握手 + 全量快照同步(`sync` 消息)
- 时钟:全部墙钟驱动(`Date.now()` 差值 + 500ms 看门狗轮询),
  手机锁屏/切后台回来立即追平,不吃定时器节流的亏
- 浏览器调试:`window.__duoDebug()` 看状态,`window.__netLog` 看连接日志,
  `__duoForceDay(n)` / `__duoKick()` 为测试辅助(仅房主)
- 本地试玩:`node serve.js` → http://127.0.0.1:8630 (开两个浏览器标签即可双人自测)
